# Nexus

Site estático de apoio a cálculos trabalhistas.

## Como executar

Extraia a pasta e abra `index.html` em um navegador. Não é necessário instalar dependências nem iniciar servidor.

## Organização

- `index.html`: página inicial.
- `pages/`: calculadoras, dúvidas e informações.
- `assets/css/main.css`: identidade visual e estilos compartilhados.
- `assets/js/`: funções comuns e lógica de cada calculadora.
- `assets/images/`: reservado para imagens do projeto.

Os resultados são estimativas. As regras podem variar conforme contrato, convenção coletiva e legislação aplicável.
